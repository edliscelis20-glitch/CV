Automatización de la carga de casos de prueba en Jira vía APITest-case loading automation in Jira via API
ContextoContextLa empresa no contaba con una herramienta dedicada de gestión de pruebas. Los casos se registraban en Jira como subtareas.The company had no dedicated test management tool. Test cases were recorded in Jira as sub-tasks.
ProblemaProblemCada caso de prueba se cargaba a mano, creando una subtarea por caso: un proceso manual y repetitivo.Every test case was loaded by hand, creating one sub-task per case: a manual, repetitive process.
SoluciónSolutionDiseñé un flujo con IA generativa: la Gema 1 genera los casos de prueba a partir de los requerimientos y la Gema 2 los transforma en un JSON masivo que contiene todos los casos. Luego, desde Postman, consumiendo la API de Jira, se insertan automáticamente todas las subtareas en el Jira padre.I designed a generative AI flow: Gem 1 generates the test cases from the requirements and Gem 2 turns them into a single bulk JSON containing all the cases. Then, from Postman, consuming the Jira API, all the sub-tasks are created automatically under the parent Jira issue.
ResultadoResultTodas las subtareas con sus casos se insertan en segundos y se eliminó por completo el proceso manual de carga.All sub-tasks with their test cases are created in seconds, and the manual loading process was eliminated entirely.
TecnologíasTechIA generativa (Gemini, ChatGPT), JSON, Postman, API de Jira.Generative AI (Gemini, ChatGPT), JSON, Postman, Jira API.
